# Starlife Pickaxe

Paper 1.21.11 custom pickaxe plugin.

## Features
- Iron pickaxe appearance.
- Netherite-level mining speed and durability behavior.
- 3x3 block mining based on the player's facing direction.
- White ash particles when blocks are mined.
- Custom persistent item ID so normal iron pickaxes are unaffected.
- Recipe uses three Nether Stars and two sticks.

## Recipe
```text
Nether Star | Nether Star | Nether Star
     Air    |    Stick    |     Air
     Air    |    Stick    |     Air
```
